# Support / 获取帮助

[Usage guide / 使用指南](docs/guide.zh-CN.md) · [English guide](docs/guide.en.md) · [Questions](https://github.com/tangyixiao/dsh-task-signal/discussions) · [Bug reports](https://github.com/tangyixiao/dsh-task-signal/issues/new/choose) · [Releases](https://github.com/tangyixiao/dsh-task-signal/releases)

For a missing sound, first report whether the settings-page preview works, whether the chosen output is the host or browser, and which system device/volume is selected. Include exact plugin, DSH and OS versions, installation source, minimal reproduction and expected behavior. Remove account identifiers, credentials, private paths and chat content. Do not upload your whole DSH home.

提示音问题请先说明“试听是否有声”“宿主系统还是当前页面”“系统输出设备与音量”，再提供插件、DSH、系统版本和最短复现。不要上传完整配置、聊天内容、令牌或个人音频。Windows 系统播放器成功退出只说明调用完成，不代替实际听感。

There is one independent maintainer and no guaranteed response time. Security issues belong in [private vulnerability reporting](https://github.com/tangyixiao/dsh-task-signal/security/advisories/new).

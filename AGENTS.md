# Repository work

Preserve unrelated dirty files, credentials, local audio and settings. Inspect branch, HEAD and diff before changes. Stage only intended paths. Never include personal imported Codex/ZCode audio in source or packages.

Use `npm run check`, `node tools/check-repository.mjs`, and package inspection for relevant changes. Source, local checks, CI, publication, installation, activation, audibility and live model inference are distinct evidence.

Keep Chinese/English README and guide entry points aligned. Banners and feature cards illustrate functionality; they are not screenshots. Character artwork and its embedded banner copies carry separate CC BY-NC-SA 4.0 terms; retain the full attribution chain. Software remains MIT.

Use one task-owned scratch namespace, reuse existing runtimes/caches, retain at least 10 GiB free, review optional growth at 1 GiB and keep it below 2 GiB. One heavy job at a time; normal logs below 20 MiB. Stop unneeded task-owned processes. Before cleanup, verify ownership, resolved boundaries, links, consumers and recovery needs. Do not bypass a rejected cleanup operation.

For dependency updates preserve valid authorship, verify linked contributor emails, review exact PR heads and checks before an authorized merge, and read back the final commit. Do not invent contribution or platform-state claims.

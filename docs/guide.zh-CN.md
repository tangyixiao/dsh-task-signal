# Task Signal 使用指南

[首页](../README.md) · [English](guide.en.md) · [获取帮助](../SUPPORT.md)

## 安装与第一次试听

DSH Desktop：打开左侧「插件 → 添加插件」，输入 `dsh-task-signal@0.1.3`，安装并启用。在「插件 → dsh-task-signal」详情页找到「任务提示音」。CLI 管理的网页 profile 可用：

```powershell
dsh plugin --profile web add dsh-task-signal@0.1.3
```

默认只开主任务完成提醒，完成音为 Codex 风格。Windows 默认选“宿主系统”；先点一次“任务完成 · 试听”。想让网页所在的电脑发声，改为“当前页面”，再点试听解锁页面音频。

## 选择声音

| 选项 | 来源与行为 |
| --- | --- |
| Codex 风格（默认） | 独立合成的近似音色；导入本机预设后播放本机音频 |
| ZCode 风格 | 独立合成的近似音色；导入本机预设后播放本机音频 |
| 六种原创音色 | 清脆叮咚、轻响、柔和铃声、上行旋律、两声叩门、低音警示 |
| 自定义 WAV | 上传一份音频，各类事件均可选择；未上传时选项禁用 |

本机预设会在菜单中标记“本机音效”。发行包不含 Codex/ZCode 的原录音，声音选择不表示官方合作。源码提供可选本机导入工具：

```powershell
node tools/import-local-sounds.mjs --codex "D:\CodexApp\app\resources\codex-notification.wav" --zcode-asar "D:\ZCode\resources\app.asar" --ffmpeg "D:\ffmpeg\bin\ffmpeg.exe"
```

路径按实际安装位置填写。导入工具仅使用已有 ffmpeg，不下载或安装；导入结果保留在你本机。自定义音频限制为 16 位 PCM WAV、单/双声道、8–48 kHz、最多 2 MiB/8 秒；删除后相关事件回退到 Codex 音。

## 提醒规则

- 任务完成、需要回答、等待授权、运行出错分别配置开关与音色。主动停止不触发完成音。
- 只监听激活后新产生的正式会话事件；刷新、历史记录不会重放。
- 子代理默认静音，可单独开启。时长阈值默认 0，每轮完成都提醒；阈值只限制完成事件。
- 默认 900ms 连续提醒间隔，同一回合去重。多个页面通过宿主领取机制避免重复页面播放。
- “仅后台提醒”依据打开页面的焦点心跳；状态 15 秒过期。没有页面或状态过期时按后台处理。
- 免打扰采用宿主电脑本地时间，支持跨午夜；开始和结束相同时不限制。
- 已激活的小鲸鱼对应事件发声时可让开。它不覆盖所有第三方提醒插件；其他插件请关闭相同事件，避免叠响。
- 临时静音在 DSH 宿主重启后恢复，不改持久总开关。语音播报与系统通知是可选项，仍需要打开页面；默认播报文稿“任务完成了”可修改。

## 声音在哪里播放

Windows 宿主播放使用隐藏的系统播放器进程；窗口后台或最小化时也可响，DSH 宿主必须保持运行。macOS 的 `afplay`、Linux 的 `aplay` 路径尚未做真机音频验证；缺少播放器时会报告错误，可改用页面播放。

页面播放需要页面保持打开，先点击试听；浏览器可能限制后台页面。系统通知需授予权限，通知本身设置为静音，避免再响一次。语音播报使用当前页面的系统语音服务，文稿在界面可见、可编辑。

## 没听到声音

1. 先点试听，确认总开关、临时静音和插件音量。
2. 看系统默认输出设备、耳机/扬声器与系统音量。播放器正常退出只证明调用完成，不能证明你已听到。
3. 核对“播放位置”：远程网页选择宿主系统时，声音来自宿主电脑。
4. 页面播放先点击试听解锁，检查浏览器是否静音。
5. 若试听有声、完成不响，检查对应事件、时长阈值、子代理、仅后台和免打扰设置。

不要为试听发起付费模型任务。需要反馈时附最短复现与版本信息，见 [SUPPORT.md](../SUPPORT.md)。

## 数据、更新和卸载

数据位于 `$DSH_HOME/dsh-task-signal/`，默认 `~/.dsh/dsh-task-signal/`：设置、可选 `custom.wav` 和本机预设 `codex.wav`/`zcode.wav`。临时 `playback-*.wav` 播放后清理。最多保留 64 条内存提醒，不记录聊天正文。设置/音频接口要求本机 DSH owner 身份；无运行时遥测或外网音频上传。

通过同一插件管理器更新。回退软件版本不回退个人设置或音频。卸载先在插件管理器停用并移除插件；个人数据保留，确认不再需要后再手动移除自己的数据目录。不要删除整个 DSH home。

源码构建无需依赖安装：`npm run check`、`node tools/check-repository.mjs`、`npm pack`。详细维护与许可证分别见 [maintenance](maintenance.md)、[软件许可](../LICENSE)、[美术说明](../assets/NOTICE.md)。

# Contributing / 参与贡献

Use [Issues](https://github.com/tangyixiao/dsh-task-signal/issues) for reproducible defects and agreed work, and [Discussions](https://github.com/tangyixiao/dsh-task-signal/discussions) for questions and ideas. English and Chinese contributions are welcome. Follow the account [code of conduct](https://github.com/tangyixiao/.github/blob/main/CODE_OF_CONDUCT.md) and [AI accountability policy](https://github.com/tangyixiao/.github/blob/main/AI_POLICY.md).

```sh
npm run check
node tools/check-repository.mjs
npm pack --dry-run
```

No dependency installation is required. Submit a scoped PR explaining the concrete behavior, version compatibility and relevant evidence. Preserve personal settings and imported audio. Never include credentials, proprietary recordings or private conversation content. Keep both README entry pages and usage guides consistent. See [AGENTS.md](AGENTS.md) and [maintenance](docs/maintenance.md).

## Dependency updates and co-authorship / 依赖更新与联合署名

Preserve the original dependency-update author and valid co-author trailers. Review the exact head and meaningful checks, verify GitHub-linked contributor emails rather than guessing, and record actual maintainer work in the PR. For an authorized squash merge, inspect author/message and read back the merged commit. CI, merge, attribution and contribution-graph visibility are separate facts. This procedure does not authorize automatic merging or history rewrites.

依赖更新保留原作者和有效署名；维护者实际审阅、验证与修正应有证据。合并前核对准确提交和检查结果，不编造邮箱、共同作者或成就。软件许可与角色美术许可分别保留。
